# marketing-campaign-analysis
Project Overview

This project analyzes customer purchasing behavior and marketing campaign performance using SQL and Power BI.

The objective was to identify:

High-performing customer segments
Most responsive customer groups
Product contribution to revenue
Preferred purchase channels

Tools Used
SQL (PostgreSQL)
Power BI

Key Analysis Performed
Data cleaning and preprocessing
Customer segmentation analysis
Response rate analysis
Product performance analysis
Channel-wise purchase analysis
KPI dashboard creation

Key Insights
Adults (31–45 age group) showed the highest response rate
Low spenders were more responsive to campaigns
Store purchases contributed the highest volume
Wines generated the highest revenue contribution
